# Мәтін анимациясы қашан шығады — ережелер

Ағылшын тілді YouTube-тағы кәсіби монтаждалған talking-head видеоларын кадрма-кадр талдаудан шыққан ережелер (12 мин видео, 0,5 с сайын 1520 кадр, сөз-деңгейіндегі транскриптпен салыстырылды).

## Басты қағида
**Тұрақты субтитр жоқ.** Мәтін видеоның тек ~15–35%-ында шығады, тек мағыналы сәттерде. Экранға кілт сөз шығады, сөйлем емес: «$50 an hour, delegate» → экранда тек `$50` + `DELEGATE`.

## Триггерлер (timeline.json элемент типімен)

| Сөйлеуде не бар | Экранда | Тип |
|---|---|---|
| Сан, ақша, пайыз, адам саны | ~1 с ease-out санауыш, астында `PER MONTH` / `ОҚУШЫ` сияқты кіші жазу | `counter` |
| Видеодағы ең күшті сан | санауыш + riser → impact + камераның бетке punch-in-і | `counter` + `"hero": true` + камера `P` |
| «Үш нәрсе…», «бірінші, екінші…» | әр пункт ДӘЛ сол сөзде қосылады, алдыңғылары экранда қалады | `list` |
| Тақырыпты/бөлімді атау | нөмірлі тізім, тарау картасы | `list` / `text` |
| Есім + лауазым | есім тақтасы (lower third) | `lowerThird` |
| Компания/клиент атаулары | логотиптер атауы айтылғанда «сплывать» (overshoot pop) | `logos` |
| «Мыңдаған адам» | айналада адам иконкалары (2–4 кадр offset) | `icons` |
| Қарама-қарсылық «А емес, Б» | А — қызыл, сызылады; Б — акцент түсте, бетті екі жақтан қоршайды | `strike` + `text` |
| Жиі берілетін жауаптар → «бұл дұрыс» | тізім + ✓ белгілері stagger-мен | `checks` |
| «Видеоны тоқтатыңыз», риторикалық сұрақ | ⏸ белгісі; үнсіз пауза кезінде N→1 кері санақ | `pause`, `timer` |
| CTA / жазылу | YouTube + батырма, доғалы курсор басады | `subscribe` |
| Себеп-салдар | ӨНІМ ↓ ТҰТЫНУШЫҒА ПАЙДА | `text` + `arrow` |

**Subscribe** 2–3 рет: хук пен дәлелден кейін (~0:40–1:00), бөлім ауысқанда, финалда. Сөзге байланбайды — «кідіріс» сәттеріне қойылады.

## Уақыт
- Сөз айтылғанға дейін мәтін шықпайды: элемент сөздің Whisper басталу уақыты + ~0,1 с-та ашылады (spring-кірудің алғашқы кадрлары сөзбен тұспа-тұс келеді).
- Маңыздысы (сан, тақырып) экранда кемінде ~1,5 с тұрады.
- Санауыш ~1 с, ease-out; бір кадрда соңғы мәнге секірмейді.
- Сөз біткен соң 0,5–1 с ұстап, бірге жоғалады. Шығу кіруден жылдам (~60%).
- Жинақталатын элементтер (тізім жолдары, ✓, логотиптер) бір уақытта емес, кезекпен шығады.

## Стиль
- Бір шрифт отбасы: тығыз гротеск (әдепкі Inter Tight). Тақырып/сан — Black/ExtraBold, UPPERCASE; кіші label — Bold, letter-spacing +0.06em; есім — Regular.
- 3 түс: ақ (`text`) + бір акцент (`accent`, әдепкі лайм `#D8F868`) + теріс мағына (`negative`, қызыл `#E80820`).
- Жұмсақ қара көлеңке — жылы/жарық фонда оқылу үшін.
- Мәтін бетті ешқашан жаппайды. Камера бетті сол жаққа ығыстырады (`S` күйі), мәтін оң бағанда.
- Қауіпсіз аймақ: шеттен 5% ішке.
